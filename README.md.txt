🎨 Fashion AI – Image Generator

A modern AI-powered image generation web app built using Next.js, TailwindCSS, and a text-to-image AI API.
Users can enter a prompt, and the system generates a stylish image instantly.

🚀 Features

✨ Generate images from text prompts

⚡ Built with Next.js (App Router)

🎨 Styled with TailwindCSS

🔑 Uses AI API (Gemini/OpenAI/StyleSync – depending on your key)

📱 Fully responsive UI

🖼️ Screenshots included

🔒 API keys secured using .env

🛠️ Tech Stack
Layer	Technology
Framework	Next.js 14+ (App Router)
Styling	Tailwind CSS
API	AI Image Generation API
State mgmt	React hooks
Package Manager	npm

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/YOUR_USERNAME/FASHION.git
cd FASHION

2️⃣ Install dependencies
npm install

3️⃣ Add your API key

Create a .env file:

NEBIUS_API_KEY=your_key_here


⚠️ Do NOT share this key publicly.

4️⃣ Run the development server
npm run dev


Open:

👉 http://localhost:3000
